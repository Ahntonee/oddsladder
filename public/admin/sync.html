sync Data Sync

Manual triggers for all scheduled sync jobs. Jobs run automatically via cron — use these for on-demand updates.

sports_soccer Sync Fixtures

Fetches upcoming fixtures from API-Football for the next 3 days.

flag Sync Results

Fetches final scores for fixtures played in the last 24h and grades predictions.

psychology Run Intelligence

Generates predictions for all unpredicted fixtures today using the Intelligence Engine.

gps_fixed Recalculate Accuracy

Recomputes all accuracy stats from the prediction_accuracy_log table.

analytics Refresh Statistics

Recomputes team_statistics, league_statistics and market stats tables.

payments Sync Odds

Fetches live bookie odds for today's fixtures from The Odds API (limited to ~16 calls/day).

smart_toy Auto-Predict Fixtures

Automatically creates prediction records for all fixtures that don't have one yet today.

content_paste Grade Pending Results

Grades any ungraded predictions where scores have been set.

auto_awesome Run Daily Specials

Selects Banker of the Day, 2-Odds picks, and Mega Accumulator from today's intelligence predictions. Runs automatically at 6:00 and 6:15 AM.

storage Sync Team Stats

Fetches historical team statistics (home/away goal averages, form) from API-Football for all active leagues. Run once before the season and then weekly. Uses ~300–500 API calls.

sports_soccer Sync Corner Stats

Fetches corner kick averages for teams with upcoming fixtures. Enables the Corners market in the intelligence engine.

history Sync H2H Data

Fetches head-to-head history for today's and tomorrow's fixtures. H2H summary is used by the confidence engine to boost prediction accuracy.

model_training Adjust Market Weights

Reads historical win rates per market and auto-adjusts market coefficients in the intelligence engine. Runs automatically every Sunday at 02:00 — use this to trigger a manual adjustment.

history_edu Seed 2-Year Historical Data

Fetches all finished fixtures for every active league for the past 2 seasons from API-Football. Populates team_statistics with real home/away goal averages and h2h_history with every match result — permanently replacing hardcoded defaults with data-driven predictions. Runs in the background (~2–3 min, ~328 API calls). Only run once or at season rollover.

science Backtest Engine

Fetches historical match results from API-Football, runs the Poisson model against each past fixture, grades its accuracy, and seeds the league reliability table. Use this once to calibrate the model before live predictions accumulate. Runs in the background — check the summary after ~2 minutes.
